# 016 Upgrade d3 v3 to v7

Phase: 4 · Current libraries for the visualisations

## Why
d3 v3 is from 2015 and needs a patch to work as a module (`web/patches/d3@3.5.17.patch`).

## Tasks
- [ ] Scales and shapes: `d3.scale.linear`/`sqrt`, `d3.svg.line`/`area` → `scaleLinear`, `line`, …
- [ ] Events: `d3.event`, `d3.mouse` → event argument, `d3.pointer`
- [ ] `d3.geom.voronoi` → d3-delaunay; `d3.geom.hull`/`polygon` → d3-polygon;
  `d3.geom.quadtree` → d3-quadtree
- [ ] Selections: enter/update patterns (`.merge` / `.join`)
- [ ] Remove the d3 patch

## Notes
Most d3 code is in `Scatterplot`, `DensityDisplay`, `Heatmap` and the thumbnails.
